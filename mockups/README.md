## ❌ Not Recommended

### **Option 2 - Gacha Neon** (27/40)

**Why skip it:**
- ⚠️ Too similar to every other gacha game (Genshin, Nikke, Blue Archive)
- ⚠️ Accessibility concerns (neon on dark = low contrast)
- ⚠️ Might feel too "game-y" for serious AI conversations

**Only choose if:** Your users are 100% gacha game players (not AI enthusiasts)

---

### **Option 5 - Parallax Depth** (20/40)

**Why avoid it:**
- ❌ Motion sickness risk (scroll-based animation)
- ❌ Poor mobile performance (touch scrolling feels janky)
- ❌ High implementation complexity (scroll listeners, motion preferences)
- ❌ Doesn't work well with chat (often not enough scroll)

**Only choose if:** You have a dedicated performance optimization team AND your app has long scrolling pages

## 🔧 Implementation Notes

### Option 1: Glassmorphic Nebula
- **CSS Variables:** 9 custom properties
- **Animations:** None (static gradients)
- **Dependencies:** None
- **Estimated Implementation:** 1 hour

### Option 2: Gacha Neon
- **CSS Variables:** 8 custom properties
- **Animations:** Floating orbs (transform only), pulsing glow (opacity only)
- **Dependencies:** None
- **Estimated Implementation:** 1.5 hours

### Option 3: Rarity-Driven System
- **CSS Variables:** 4 rarity tiers × 7 properties = 28 total
- **Animations:** CSS transitions (0.8s cubic-bezier)
- **Dependencies:** PersonaContext (rarity field)
- **Estimated Implementation:** 1 hour

### Option 4: Minimalist Mesh
- **CSS Variables:** 3 custom properties
- **Animations:** None
- **Dependencies:** None
- **Estimated Implementation:** 30 minutes

### Option 5: Parallax Depth
- **CSS Variables:** 4 custom properties
- **Animations:** JavaScript scroll listener + transform
- **Dependencies:** `prefers-reduced-motion` detection
- **Estimated Implementation:** 2.5 hours

### Option 6: Glassmorphic + Rarity Hybrid ✨ **NEW**
- **CSS Variables:** 4 rarity tiers × 10 properties = 40 total (includes glassmorphism + rarity colors)
- **Animations:** CSS transitions (0.8s cubic-bezier) for rarity changes
- **Dependencies:** PersonaContext (rarity field)
- **Estimated Implementation:** 1.5 hours
- **Note:** Combines Option 1 + Option 3 systems
