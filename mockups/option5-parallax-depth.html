Option 5: Parallax Depth Layers

Tagline: "3D in 2D, Scroll-Based Magic"

⚠️ Accessibility & Performance Concerns

This option has significant drawbacks. Scroll animations can cause motion sickness, hurt mobile performance, and require careful `prefers-reduced-motion` handling. Consider other options first.

Description

Three layers moving at different speeds create a 3D depth illusion. Background gradient moves slowest, nebula clouds at medium speed, stars move fastest. Scroll down this page to see the parallax effect in action!

Pros

  • ✅ Immersion (parallax creates "depth" illusion, proven in games)
  • ✅ Delight (subtle motion rewards exploration)
  • ✅ Unique (few chatbots use parallax - differentiation)

Cons

  • ❌ Motion Sickness (some users sensitive to scroll-based animation)
  • ❌ Mobile Complexity (touch scrolling might feel janky)
  • ❌ Accessibility (MUST disable for prefers-reduced-motion)
  • ❌ Performance Risk (scroll listeners can drop frames if not optimized)
  • ❌ Short Pages (chat interface might not scroll enough to see effect)
  • ❌ Implementation Complexity (scroll detection, motion preferences, mobile tuning)

Performance Considerations

• Scroll listeners run on every frame (16.7ms budget)
• Three DOM transforms calculated per scroll event
• Mobile devices may struggle with smooth 60fps
• `will-change: transform` helps but increases GPU memory
• Must disable for `prefers-reduced-motion` users

Accessibility Requirements

CRITICAL: This effect MUST be disabled for users who have enabled "Reduce Motion" in their OS settings. Scroll-based animations can trigger vestibular disorders and motion sickness.

The mockup already includes CSS to disable parallax when `prefers-reduced-motion: reduce` is detected.
