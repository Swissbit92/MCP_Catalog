# Character Showcase & Bio Feature - HOME_UX.md

## Overview

Add a mystical, gacha-style character showcase to the home page featuring all available characters with their biographies. Inspired by Honkai Star Rail's character showcase page (https://hsr.hoyoverse.com/en-us/character?worldIndex=9&charIndex=4).

**Key Features:**
- Public character showcase (no login required)
- Gacha-style mystical UI with animations and effects
- Character cards on the left, detailed bios on the right
- CV-style bios (120-220 words) generated by LLM via `/persona/summary` API
- Smooth navigation between characters with URL parameters
- Mobile-responsive design (stacks vertically on mobile)
- Additive feature - doesn't replace existing gacha functionality

## Technical Requirements

### API Integration
```typescript
interface CharacterBio {
  key: string;
  summary: string; // 120-220 words CV-style bio from LLM
  hash: string;
  updated: string;
}

// Add to existing src/services/api.ts
export const fetchCharacterBio = async (personaKey: string): Promise<CharacterBio> => {
  const response = await fetch(`${API_BASE_URL}/persona/summary`, {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ persona: personaKey })
  });
  return response.json();
};
```
