# Honkai Star Rail Character Showcase - HOME_UX.md

## Overview

Recreate the authentic Honkai Star Rail character showcase experience with full-screen character posters in a horizontal carousel, overlay information panels, and smooth transitions. Based on deep analysis of the actual HSR character page (https://hsr.hoyoverse.com/en-us/character).

**Key Features:**
- Full-screen character posters as the main visual element
- Dynamic background images that change per character
- Overlay information panels with character details and bios
- Horizontal carousel navigation with smooth transitions
- Character selector dots/thumbnails at bottom for quick navigation
- Voice actor language toggle (EN/CN/JP versions)
- Audio controls for character voice lines
- Professional presentation with voice actor credits and quotes
- URL parameter support for direct character linking
- Mobile-responsive carousel design with touch gestures
- CV-style bios (120-220 words) generated by LLM via `/persona/summary` API

## Technical Requirements

### API Integration
```typescript
interface CharacterBio {
  key: string;
  summary: string; // 120-220 words CV-style bio from LLM
  hash: string;
  updated: string;
}

interface CharacterData {
  key: string;
  name: string;
  poster: string; // Full character poster image
  background: string; // Full-screen background image
  voiceActors: {
    en: string;
    cn?: string;
    jp?: string;
  };
  bio: string; // Character story/lore
  quote?: string; // Character quote/subtitle
  rarity?: string;
  audioFiles?: {
    en?: string;
    cn?: string;
    jp?: string;
  };
}

// Add to existing src/services/api.ts
export const fetchCharacterBio = async (personaKey: string): Promise<CharacterBio> => {
  const response = await fetch(`${API_BASE_URL}/persona/summary`, {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ persona: personaKey })
  });
  return response.json();
};
```
