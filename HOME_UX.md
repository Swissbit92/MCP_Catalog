# Honkai Star Rail Character Showcase - HOME_UX.md

## Overview

Recreate the authentic Honkai Star Rail character showcase experience with overlay panels that slide in from the right, featuring character images on the right side and information on the left side. Based on deep analysis of the actual HSR character page (https://hsr.hoyoverse.com/en-us/character).

**Key Features:**
- Overlay panel slides in from right side with character image positioned on right
- Character information and bio displayed on left side of same panel
- Bio text fades in from bottom up with smooth animation
- Fantasy/gacha-themed borders with rarity-based colors and non-symmetrical styling
- Horizontal carousel navigation with smooth transitions
- Character selector dots/thumbnails at bottom for quick navigation
- Voice actor language toggle (EN/CN/JP versions)
- Audio controls for character voice lines
- Professional presentation with voice actor credits and quotes
- URL parameter support for direct character linking
- Fully responsive design that adapts to window size
- CV-style bios (maximum 50 tokens) generated by LLM via `/persona/summary` API

## Technical Requirements

### API Integration
```typescript
interface CharacterBio {
  key: string;
  summary: string; // Maximum 50 tokens CV-style bio from LLM
  hash: string;
  updated: string;
}

interface CharacterData {
  key: string;
  name: string;
  poster: string; // Full character poster image
  background: string; // Full-screen background image
  voiceActors: {
    en: string;
    cn?: string;
    jp?: string;
  };
  bio: string; // Character story/lore
  quote?: string; // Character quote/subtitle
  rarity?: string;
  audioFiles?: {
    en?: string;
    cn?: string;
    jp?: string;
  };
}

// Add to existing src/services/api.ts
export const fetchCharacterBio = async (personaKey: string): Promise<CharacterBio> => {
  const response = await fetch(`${API_BASE_URL}/persona/summary`, {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ persona: personaKey })
  });
  return response.json();
};
```

## Risks & Mitigations

### Risk: Complex Carousel Implementation
**Mitigation:** Use established carousel libraries, start with basic functionality

### Risk: Background Image Performance
**Mitigation:** Implement lazy loading and preloading for adjacent characters

### Risk: Mobile Touch Gestures
**Mitigation:** Use touch libraries, test extensively on mobile devices

### Risk: Animation Performance
**Mitigation:** Use CSS transforms, monitor frame rates, optimize for 60fps

### Risk: Breaking Existing Functionality
**Mitigation:** Additive approach - integrate below existing gacha buttons
