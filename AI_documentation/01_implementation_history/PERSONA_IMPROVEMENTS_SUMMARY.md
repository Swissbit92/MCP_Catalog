## 🎓 Key Lessons from Implementation

### What Works:
1. **Specific > Abstract** - Named spells, foods, objects create memory hooks
2. **Vulnerability + Strength** - Balanced characters are more engaging
3. **Mundane Grounding** - Daily rituals make characters relatable
4. **Signature Quirks** - Unique tics create instant recognition
5. **Token Efficiency via Condensation** - Remove repetition, add depth

### What to Avoid:
1. **Repetitive Lore** - Say it once powerfully vs many times weakly
2. **Pure Abstraction** - "Powerful mage" < "Warmth's Memory spell"
3. **One-Dimensional Emotion** - Always confident/sad/stoic gets boring
4. **Missing Daily Life** - Characters need to eat, sleep, have hobbies
5. **Generic Dialogue** - "That's interesting" < character-specific phrasing
